Nonsense, Austen

In-Browser LLM Text Generation & WebGPU/WASM Example

ChatGPT and large language models are often viewed as mysterious, monolithic systems running on water-hungry data centers. However, ChatGPT 2 was open source and Andrej Karpathy's nanoGPT showed that the core mechanics of a generative transformer can be written in just a few hundred lines of Python (train, model, and infer).

This project takes that architecture a step further by bringing implementing inference entirely within a single WASM web app. Where possible, it generates Austen-like prose locally and entirely within your web browser. No server, no external API calls, and no internet connection required once the page loads.

By compiling the model weights and orchestration layer to run client-side, this page can run a dedicated inference cycle on everyday hardware. On a 2019 MacBook Pro (i5 with integrated graphics), it generates 500 characters of somewhat coherent, Jane Austen-styled prose in under 30 seconds. Provided your browser is up to date and you are using a laptop or desktop computer (not a mobile), your computer handles the entire autoregressive inference itself.

Engineering & Architecture Notes

  • Make your own: Developers can download the training code to build their own version using corpora like Shakespeare or Tolstoy. Training a target model of this scale takes under 15 minutes on a modern desktop NVIDIA GPU.
  • Mobile Fallback: To prevent battery drain on mobile browsers, the application simulates inferences but uses pre-calculated data on mobiles.
